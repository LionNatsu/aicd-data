# AICD Data

Game data and assets for [AICD](https://github.com/LionNatsu/aicd).

## Data

- `data/items.json` — Item catalog (id, tier, transportType, asTarget)
- `data/recipes.json` — Recipe definitions (inputs, outputs, craftingTime)
- `data/facilities.json` — Facility definitions (buffers, power, placement caps)

## Images

- `images/items/` — Item icons (PNG), named `{itemId}.png`
- `images/facilities/` — Facility icons (PNG), named `{facilityId}.png`

## i18n

- `i18n/zh-Hans/item.json` — Chinese item names
- `i18n/zh-Hans/facility.json` — Chinese facility names

## Sources

- Game data aligned with [endfield-calc](https://github.com/JamboChen/endfield-calc) (MIT License)
- Item/facility icons from [endfield-calc](https://github.com/JamboChen/endfield-calc)
